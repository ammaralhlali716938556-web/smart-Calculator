# 🦁 تطبيق حاسبة أبو أسد (Abu Asad Calculator)

تطبيق آلة حاسبة أندرويد فاخر، أنيق وعصري يحمل اسم وشعار **"حاسبة أبو أسد"**.  
تم تجهيز هذا المستودع بالكامل ليتم رفعه على **GitHub**، حيث يقوم **GitHub Actions** تلقائياً ببناء التطبيق واستخراج ملف الـ **APK** الجاهز للتحميل والتثبيت المباشر على هاتفك الأندرويد دون الحاجة لأي برامج إضافية على جهازك!

---

## ✨ مميزات التطبيق

1. **تصميم ملكي فاخر وراقي:**
   - واجهة داكنة ملكية (Deep Obsidian Dark) مع لمسات وتدرجات ذهبية فخمة مستوحاة من هيبة الأسد.
   - في أعلى واجهة التطبيق يظهر العنوان الرئيسي الفخم: **"حاسبة أبو أسد"** مصحوباً بأيقونة الأسد الذهبي وشعار فخامة الحساب.
   - أيقونة التطبيق الرسمية تحمل رأس الأسد الملكي باللون الذهبي الباهر.

2. **العمليات الحسابية الأربعة الأساسية:**
   - الجمع (`+`)
   - الطرح (`−`)
   - الضرب (`×`)
   - القسمة (`÷`)
   - النسبة المئوية (`%`)
   - تغيير الإشارة موجب/سالب (`±`)
   - الحذف خطوة بخطوة (`⌫`) ومسح الكل (`C`)

3. **دقة حسابية متناهية:**
   - استخدام مكتبة `BigDecimal` لتفادي أي أخطاء عشرية، مع معالجة ذكية للقسمة على صفر.
   - تنسيق الأرقام تلقائياً بفواصل الآلاف لسهولة القراءة (مثل `1,000,000`).
   - استجابة لمسية واهتزاز خفيف (Haptic Feedback) عند الضغط على الأزرار لشعور راقٍ بالتحكم.

4. **توافق كامل وشامل:**
   - مصمم ليعمل بسلاسة وثبات على أي هاتف أندرويد من نظام أندرويد 5.0 (Lollipop) وحتى أحدث إصدارات أندرويد 14 و 15 ومستقبلاً.

## 🚀 طريقة رفع المشروع إلى GitHub والحصول على الـ APK الجاهز

لقد تم إعداد مسار عمل آلي بالكامل داخل مجلد `.github/workflows/build-apk.yml`. كل ما عليك فعله هو الآتي:

### الخطوة 1: إنشاء مستودع جديد على GitHub
1. افتح موقع [GitHub](https://github.com) وقم بتسجيل الدخول.
2. اضغط على زر **New** لإنشاء مستودع جديد (Repository).
3. اختر اسماً للمستودع (مثلاً: `abu-asad-calculator`) واجعله **Public** أو **Private** كما تشاء، ثم اضغط **Create repository**.

### الخطوة 2: رفع ملفات المشروع إلى المستودع
يمكنك رفع الملفات بإحدى طريقتين:

#### الطريقة الأولى (الأسهل بدون أوامر):
1. قم بفك ضغط ملف `AbuAsadCalculator.zip`.
2. في صفحة مستودعك على GitHub، اضغط على زر **Add file** ثم اختر **Upload files**.
3. اسحب جميع الملفات والمجلدات (بما في ذلك مجلد `.github` ومجلد `app` وملفات `build.gradle` وغيرها) وأفلتها في المتصفح.
4. اضغط على زر **Commit changes** بالأسفل.

#### الطريقة الثانية (عبر موجه الأوامر Git):
```bash
git init
git add .
git commit -m "الإصدار الأول من تطبيق حاسبة أبو أسد 🦁"
git branch -M main
git remote add origin https://github.com/اسم_حسابك/abu-asad-calculator.git
git push -u origin main
```

## 📥 كيف تقوم بتحميل ملف الـ APK بعد الرفع؟

بمجرد رفع الملفات، سيبدأ GitHub تلقائياً ببناء التطبيق:

1. اضغط على تبويب **Actions** في أعلى صفحة المستودع في GitHub.
2. ستجد عملية بناء تعمل باسم **"🦁 بناء تطبيق حاسبة أبو أسد (APK)"**.
3. انتظر دقيقة إلى دقيقتين حتى تظهر علامة الصح الخضراء ✅.
4. اضغط على اسم العملية، ثم انزل لأسفل الصفحة في قسم **Artifacts**، ستجد ملف:
   👉 **`AbuAsad_Calculator_v1.0_APK`**
5. اضغط عليه لتحميله فوراً وتثبيته على هاتفك الأندرويد!
6. كما سيقوم النظام تلقائياً بإنشاء **Release** رسمي في صفحة **Releases** للمستودع مرفق به ملف `AbuAsad_Calculator_v1.0.apk` لتحميل مباشر برابط دائم.
